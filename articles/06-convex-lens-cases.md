# 凸透镜成像为什么要检查 f 和 2f

在理想近轴模型中，$u$ 为物距，$f>0$ 为焦距，$v$ 为有符号像距。实像一侧的 $v$ 取正，物体一侧的 $v$ 取负。由两条典型光线的交点可得 $v=fu/(u-f)$，像高与物高的有符号比为 $-v/u$。

| 物体位置 | 符号与倍率 | 观察结论 |
| --- | --- | --- |
| $u>2f$ | $v>0$，$0<v/u<1$ | 倒立缩小实像 |
| $u=2f$ | $v=u>0$ | 倒立等大实像 |
| $f<u<2f$ | $v>0$，$v/u>1$ | 倒立放大实像 |
| $u=f$ | 理想出射光平行 | 有限距离屏上无清晰像 |
| $0<u<f$ | $v<0$，$-v/u>1$ | 正立放大虚像 |

在几何有迹体验版的「凸透镜成像」中可以分别改变物距和焦距。固定 $f$，把物体从远处向焦点移近，先找等大位置，再看像距怎样变化。物体非常靠近焦点时，像点可以远超图框，应读像距和成像性质。

真实透镜的厚度、光阑、像差和有限屏幕会影响观测。这张图用于推导判断条件，实验仍需用器材找清晰光斑并读数。
