# 用一个可拖动题目解释多解自测

八年级动点题常会要求「所有时刻」。几何有迹公开版的绕边面积实验提供了一个可复核的例子：面积为 11 时有两个有效时刻，$11/3$ 和 $(7+\sqrt 5)/2$。

## 数值小问怎样比较

题目存储目标值，答题输入支持小数、分数和根式。分隔出的每个算式先进行数量解析，再把得到的数与目标值比较。当前容差约为 0.005，覆盖正确的两位小数近似。自测以一组数值为目标，所以调换顺序也能通过。重复填入同一个数只算一个答案。

| 可在公开版复核的输入 | 预期结果 |
| --- | --- |
| `3.67,4.62` | 两项正确 |
| `4.62,3.67` | 两项正确 |
| `3.67` | 少一个解 |
| `3.67,4.62,5` | 多出一个值 |

## 从系统反馈回到原题

得到「还有解没找到」时，可以先问自己是否列齐了分段。打开图形验证，在面积曲线上找水平线 $S=11$ 的交点，再用每段的定义域核验。看到「还有数值不符合条件」时，则更适合先检查代回：方程的代数根可能落在当前分段以外。自测检查的是小问的数值，完整证明要说明为什么没有其他解。

本例面向间隔远大于数值容差的答案。遇到两个正确答案本就十分接近的题目，应改用更精细的精度规则、精确表达式或其他合适的判分方式。
