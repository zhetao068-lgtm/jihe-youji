# 几何有迹：生成与验证路径

生成入口统一管理输入与输出，依次完成内容生成、Windows 与 Android 构建、交互验证、签名与权限检查、隐私扫描及打包。

当前完整目录含 147 项数学、48 项物理；公开体验版含 22 项数学、10 项物理。每项提供自测和题型边界。目录覆盖范围以实际条目为准。

## 交付路径

- 桌面统一入口指向最近一次通过验证的安装包，内含「数理模型库」和「公开体验版」两个目录。
- 每次生成使用独立工作目录。构建日志和中间文件留在维护端，交付包只收录安装文件、说明和校验值。
- 两个版本均通过验证后才切换最新版入口。失败构建保留诊断记录，先前已验证版本继续可用。
- 更新最新版时保留上一版；并行生成会被互斥锁拦截，避免互相覆盖。
